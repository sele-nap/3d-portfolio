# sele-nap.github.io

Personal portfolio — an interactive 3D tarot card scene built with React and Three.js.

## Stack

- React 19 + TypeScript
- Three.js · @react-three/fiber · @react-three/drei
- Vite

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` automatically deploy to GitHub Pages via GitHub Actions.
